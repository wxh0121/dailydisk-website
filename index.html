工作原理

清晨五点，一次清点

05:00完整清点
  1. 开始

    清晨，完整清点

    05:00 读取全部文件元数据。登录时也会检查待办，当天已完成则跳过。运行结束即退出。

  2. 补上变化

    补上扫描中的改动

    清点时同步记录 FSEvents，扫描期间的改动一并计入，不依赖前一天的日志。

  3. 比对

    只写下变了的部分

    与当前清单逐批比对，只保存变化。未变的文件不重写，旧值保留 24 小时以备恢复。

  4. 核对删除

    核对已删除的文件

    遍历结束后确认哪些文件已经消失。读不到的目录沿用上一次的记录。

  5. 发布

    写下报告

    报告以 JSON 与 Markdown 成对保存，在「历史」中查看。超过阈值才通知，通知只含总字节数。

隐私

数据只留在这台 Mac 上。

不联网

监视器不发出网络请求。没有遥测，不用云存储。

无需管理员权限

不用 root、sudo 或 LaunchDaemon，只有一个用户级 LaunchAgent。

路径默认隐藏

显示路径仅限当前会话，导出完整 JSON 需再次确认。

通知不含路径

通知只给总字节数。日志中的敏感字符串经过哈希。

终端 · 一次性试用安装
# 1. 安装 Apple 命令行工具（已安装可跳过）
xcode-select --install
# 2. 获取源码
git clone https://github.com/Nu1sance/DailyDisk.git
cd DailyDisk
# 3. 构建、签名并安装到 ~/Applications
ALLOW_ADHOC_SIGNING=1 Scripts/build-app.sh --install
open "$HOME/Applications/DailyDisk.app"

临时签名仅供试用，重新构建后可能需要重新授予「完全磁盘访问权限」。长期使用请准备本地签名身份，见 用户文档 · 安装。当前为源码发行，没有公证安装包，也没有自动更新。
